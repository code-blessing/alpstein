# Project Guidance

## Generated code

This project is using heavily generated code. Do focus on the none-generated code
in the base directories not starting or ending with generated.


## Comments

Do not add a comment to every method. Most methods should have no comment at all —
a clear name and clear code are the documentation.

Only write a comment when there is something genuinely important to say, and only
when it is about something *inside* the method: a non-obvious algorithm, a subtle
edge case, a workaround, or a reason why the code does something surprising.

Never write comments that just restate the method's name or signature.
